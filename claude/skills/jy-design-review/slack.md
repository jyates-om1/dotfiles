# Stakeholder messages

One draft per stakeholder, saved to `slack-drafts.md`. Never sent by the agent; the user reviews and sends.

Shape (aim for under 120 words):

```
Hi <Name>! <One sentence: what this is.> What I need from you:
- **<ID>:** <the ask, one line>
- **<ID>:** <the ask, one line>
<Link to their subsection in the doc>. Pick Agree / Change / Discuss in the Decision column and comment if Change or Discuss. <Optional: a 15- or 30-minute ask, with whom.>
```

Rules:
- The asks come first, before any context.
- Link the reader's own subsection, not the doc's top.
- One sentence of context at most; the doc carries the rest.
- Anyone who changes code or infrastructure owned by someone not in the review gets a separate heads-up, sent first.
- Before sending, the doc must be shared with each recipient as an **Editor**, or they can't set dropdowns.
